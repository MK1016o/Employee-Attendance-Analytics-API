### Examined and Decided Not a Defect
1. **Calendar values stored as strings (`"YYYY-MM-DD"`, `"HH:MM"`):** We examined whether dates and shift times should be stored as BSON datetimes. We confirmed this is **intentional** per DATA_MODEL.md section 1 ("Calendar dates and times of day are plain strings on purpose: a date is not an instant, and turning it into one forces a time zone on it").
2. **Missing `half_day` or `history` on seeded documents:** Some seeded documents lack `half_day` or `history`. DATA_MODEL.md notes this represents legacy data where missing implies `false` and `[]` respectively; treating missing as defaults rather than an error is intended behavior.
3. **Derived fields ignored in request bodies:** If clients send `work_hours` or `late_minutes`, the API does not error out; openapi.yaml explicitly instructs the server to ignore client-supplied derived fields and compute them authoritatively.
